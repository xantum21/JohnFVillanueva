## Automated verification

Run from the repository root:

```bash
python3 check-site.py
node --check assets/site.js
python3 build-public-resume.py
```

`check-site.py` verifies all HTML documents for local references, essential
metadata, a single primary heading, canonical URLs, duplicate IDs, image alt
text, labeled controls, safe external links, privacy rules, navigation parity,
and exact canonical sitemap coverage.
